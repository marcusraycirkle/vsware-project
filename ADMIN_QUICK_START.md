# 🚀 Admin Portal Quick Start Guide

## Welcome to MISpal Administrator Portal!

This guide will help you get started with the new administrator portal in just 5 minutes.

## 🎯 What's New?

The administrator portal is a **complete redesign** specifically for principals and school administrators. It features:

- ✨ Modern, clean interface inspired by tyro.school
- 🎨 Full customization options (colors, branding, layout)
- 👥 Comprehensive student & teacher management
- 📊 Real-time analytics and insights
- ⚙️ Complete school settings control
- 🔒 Advanced user management with role-based access
- 💬 Communication tools (messages & announcements)

**Note**: The teacher portal remains separate and unchanged.

## 🔐 Access the Admin Portal

### Step 1: Navigate to Admin Portal
Visit: `https://your-domain.com/admin`

Or from the home page:
1. Go to `https://your-domain.com/`
2. Click "Staff Login"
3. Select your school
4. Login with admin credentials

### Step 2: Login
- **Email**: Your admin email
- **Password**: Your admin password
- **Role**: Must be "Principal" or "Admin"

### Default Credentials (Development)
```
Email: admin@school.ie
Password: Admin123!
Role: Principal
```

## 🎨 First-Time Setup (5 Steps)

### 1️⃣ Configure School Information
📍 **Navigation**: Settings > School Settings

Update:
- School name
- Address and location
- Phone and email
- Academic year dates (term start/end)

Click **"Save Settings"**

### 2️⃣ Customize Your Portal
📍 **Navigation**: Settings > Customization

Personalize:
- **Colors**: Choose primary and accent colors
- **Branding**: Upload your school logo
- **Theme**: Select light/dark mode
- **Layout**: Adjust sidebar and header preferences
- **Typography**: Choose font style and size

Click **"Save Changes"**

### 3️⃣ Add System Users
📍 **Navigation**: Settings > User Management

Add teachers and staff:
1. Click **"Add User"**
2. Enter name and email
3. Assign role (Teacher, Admin, Staff)
4. Set password
5. Click **"Create User"**

### 4️⃣ Import Students
📍 **Navigation**: Students

Two options:
1. **Manual**: Click "Add Student" for individual entries
2. **Bulk Import**: Click "Import" to upload CSV file

CSV Format Required:
```csv
firstName,lastName,studentId,email,yearGroup,dateOfBirth
John,Smith,STU001,john@email.com,1,2015-05-15
```

### 5️⃣ Add Teachers
📍 **Navigation**: Teachers

Add teaching staff:
1. Click **"Add Teacher"**
2. Enter personal information
3. Assign subjects
4. Set email and contact details
5. Click **"Save Teacher"**
